# 1. key là gì? (Hiểu đúng bản chất)

File này giải thích sâu về `key` trong `v-for`: nó là gì, Vue dùng nó lúc nào, và vì sao dùng sai (như lấy index) còn nguy hơn không dùng. Đọc để tránh cả rổ bug "input nhảy dữ liệu".

Trong `v-for`, key là định danh duy nhất giúp Vue biết:

👉 Phần tử DOM / component này tương ứng với item dữ liệu nào

Ví von: `key` là **số báo danh của thí sinh** — khi danh sách bị xáo trộn, giám thị (Vue) đối chiếu số báo danh chứ không đối chiếu chỗ ngồi (index), nên không ai bị "đội lốt" ai.

> 📄 **Code ví dụ:** [`examples/01-1-key-la-gi-hieu-ung-ban-chat.html`](examples/01-1-key-la-gi-hieu-ung-ban-chat.html)

> item.id = danh tính

Vue dùng key để:

- So sánh trước & sau khi dữ liệu thay đổi
- Quyết định:
  - Giữ lại DOM cũ
  - Di chuyển DOM
  - Hay tạo DOM mới

👉 **Không có key = Vue đoán theo index**

# 7. Quy tắc của key (rất quan trọng)

Mục này chốt "tiêu chuẩn mối" cho một key tốt: duy nhất, ổn định, và là kiểu nguyên thủy.

`key` phải:

- ✔ Duy nhất
- ✔ Ổn định (không đổi)
- ✔ Kiểu nguyên thủy (string | number)

❌ Không dùng:

```
:key="item"          // object
:key="Math.random()" // luôn đổi
:key="Date.now()"    // luôn đổi
```

# 8. Vue dùng key khi nào?

Vue dùng `key` khi:

- diff DOM
- patch component
- quyết định:
  - reuse
  - move
  - destroy
  - create

👉 `key` ảnh hưởng trực tiếp đến hiệu năng + correctness

# 9. Best Practice (chuẩn công nghiệp)

Mục này gom lại thành "quy tắc nhà nghề": lúc nào bắt buộc có key, lấy key ở đâu, và những thứ không bao giờ được làm key.

✅ Luôn có key khi:

- `v-for` + component
- `v-for` + input
- list có thêm / xoá / sort

✅ Ưu tiên:
- id từ backend
- uuid

❌ Tránh:
- `:key="index"`
- `:key="object"`
- `:key="random"`

# 10. Ghi nhớ nhanh (1 câu)

🔑 `key` không dành cho Vue — mà dành cho DOM & component state

Nếu không có `key`, Vue:

- update nhanh hơn
- nhưng có thể sai logic.

> **Tóm gọn 1 câu:** `key` là thẻ căn cước của item — duy nhất, ổn định, kiểu nguyên thủy; thiếu nó Vue nhanh hơn một chút nhưng đổi state sai là chuyện có thể xảy ra.
